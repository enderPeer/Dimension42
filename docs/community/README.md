# Community sharing

Source project: https://github.com/enderPeer/Dimension42

The README, runnable CPU demonstration, reproduction commands, and a small verified trace sample
are available in the repository. The texts below are drafts; no external posts are implied.

## Hacker News: manual submission

Requested title:

> Show HN: Dimension42 – Exhaustively mapping 1.1T 5-byte programs to analyze self-modifying logic

URL: https://github.com/enderPeer/Dimension42

[HN's guidelines](https://news.ycombinator.com/newsguidelines.html) ask users not to automate posting
or publish generated text. The project owner should write and submit the final title/comment personally,
adjusting the title to the submission form's limit. No AI-written HN comment is supplied.
The [Show HN guidelines](https://news.ycombinator.com/showhn.html) also ask for something people can try;
the CPU demo provides that entry point.

and exhaustive verification metadata for five programs. The data links back to this repository.
